# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Git tag-based semantic versioning system
- Comprehensive test suite with unit and integration tests
- Multi-platform CI/CD pipeline with GitHub Actions
- Automated binary releases for Linux, macOS, and Windows
- Local build, test, and release scripts
- Docker container support
- Installation documentation
- Code coverage reporting
- Security audit checks
- Performance benchmarking

### Changed
- Updated GitHub Actions workflows for better CI/CD
- Improved version management with git tags
- Enhanced build process with cross-platform support

### Fixed
- Version reporting now uses git tags when available

## [0.2.1] - 2024-01-01

### Added
- Initial release with basic font searching capabilities
- Support for OpenType variation axes
- Support for OpenType features
- Support for OpenType scripts
- Support for font tables
- Unicode character support
- Font name pattern matching
- JSON output format
- Parallel processing
- Progressive output

### Changed
- Improved performance with memory mapping
- Better error handling

### Fixed
- Various bug fixes and improvements
